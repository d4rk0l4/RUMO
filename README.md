# RUMO — Esports Career Simulator

A lightweight browser-based career simulator prototype for CS2 and VALORANT.

## Playable prototype
Open `index.html` in a modern browser. No Node.js, Python, or build step is required.

Includes:
- Player creation with nickname, jersey name, number, nationality, game, and role.
- Fixed starting age: 16.
- Random Academy assignment based on nationality.
- Orange and graphite interface.
- Clutch training with tactical clues and decisions.
- Local browser save using localStorage.

## GitHub Pages
A GitHub Actions workflow deploys the site. In repository Settings → Pages, choose **GitHub Actions** as the source if it is not already enabled.

## Disclaimer
Independent fan-made simulator. Not affiliated with Valve or Riot Games. Teams and match situations are simulated.
